# 競馬自動投票

スマホから予想テキストを送ると、決めたルールで馬券にして、発走の数分前に自動で投票するアプリです。
中央（即PAT）と地方（SPAT4）に対応しています。

## 買い方のルール

**◎★の買い方（平日も土日祝も）**
- ◎と★があるレース：**単勝◎**（増額ルール）＋**ワイド◎-★** 各100円（流しで買う）＋**複勝★** 各100円
- ★だけのレース：**複勝★** 各100円
- 土日祝で◎だけのレース：単勝◎だけ
- 単勝は100円から始め、外れるたびに100円ずつ増やします（毎日100円から）
- 投票の直前に単勝オッズを読み、**2.1倍以下なら単勝だけ見送ります**
- **単勝が一度当たったら、その日はそれ以降、単勝だけ買いません**（ワイド・複勝・転がしは続けます）
- 前のレースの単勝が未確定のまま次の締切が来たら、「外れ」とみなして増やして買います（設定で「見送る」に変更可）
- 1日の**上限は10,000円**（平日・土日祝それぞれ設定可。転がしの資金とは別）。超える買い目は保留にして、スマホで「買う／見送る」を選びます

**平日の複勝◎の転がし**
- ◎のあるレースで、**複勝◎**を転がします（◎★のレースは、上の◎★の買い方と**両方**）
- 500円で買い、当たったら払戻金を**全額**次のレースへ（100円未満の端数は残す）
- **4回連続で的中**したら終了。外れたら500円から再挑戦し、**資金3,000円**を使い切ったら終了
- 前のレースの払戻が確定する前に次のレースの締切が来た場合、転がしはそのレースを見送ります

金額などの数字はすべてアプリの「設定」で変えられます。

## 予想の書き方

```
新潟
1R ★ 3.7.10
2R ◎ 4 ★ 5.7.9

東京
11R ◎ 2 ★ 3.6.9.12
11R 15:40 ◎ 2 ★ 3.6   ← 発走時刻は書いても書かなくてもよい
```

- 全角数字・全角スペース・「.」「・」「、」区切りでも読めます
- 発走時刻はnetkeibaのレース一覧から自動で取得し、取れなければ投票サイトの画面から読みます。それでも取れないときはスマホに通知が来るので、アプリで入力してください

## 仮想収支

「仮想収支」タブに日付と予想を貼ると、netkeibaからその日の結果（着順・最終オッズ・払戻）を取り込み、上のルール通りに賭けた場合の収支を計算します。

- 「発走5分前に投票、発走10分後に結果が分かる」として、本番と同じ順序で計算します（前のレースの結果待ちによる増額や見送りも再現します）
- 単勝2.1倍以下の判定は最終オッズで行います。本番は直前オッズなので、少しずれることがあります
- 上限を超えた日は「上限超え」と表示します（本番なら保留になるところ）

## 3つの投票モード

| モード | 動き |
|---|---|
| 練習 | 投票サイトに接続しません。結果はnetkeibaから取り込み、ルール通りに進みます（ペーパートレード） |
| リハーサル | 投票サイトにログインし、購入ボタンの直前まで入力して止めます。画面を撮影して残します |
| 本番 | 実際に購入します。サーバーの `.env` で `ALLOW_LIVE=1` にしたときだけ選べます |

**必ず「練習」→「リハーサル」→「本番」の順に進めてください。**

## 安全装置

- 購入前に、確認画面の合計金額がアプリの計算と一致するかを確認し、違えば購入しないで中止します
- 購入ボタンを押した後にエラーが起きた場合は自動でやり直さず、「要確認」としてスマホに通知します（二重購入を防ぐため）。購入履歴を見て、アプリで「買えていた／買えていなかった」を押してください
- 投票中にサーバーが再起動した場合も「要確認」にします
- 同じレースは二重に予約できません
- ログイン情報はサーバーの `.env` だけに置き、データベースや画面には出しません

## はじめ方（3ステップ）

### 1. VPS（レンタルサーバー）を借りる
- 日本の会社のVPSを1台借ります（さくらのVPS、ConoHa VPS、Xserver VPS など。月500〜1000円くらい）
- 申し込むときは **OS に「Ubuntu」**、**メモリ 1GB 以上** を選びます
- 投票サイトが海外からの接続を制限していることがあるので、必ず日本の会社を選んでください

### 2. 1行貼り付けて、質問に答える
VPSの管理画面にある「コンソール」（ブラウザで黒い画面が開く）にログインし、次の1行を貼り付けてEnterを押します。

```
curl -fsSL https://raw.githubusercontent.com/taroryu63/keiba-autobet/main/install.sh | sudo bash
```

日本語で質問が出るので答えてください（アプリのパスワード、即PAT・SPAT4の番号）。
暗証番号などは入力しても画面に表示されませんが、入力はされています。
終わると、スマホで開くアドレスと通知用のトピック名が表示されます。ドメインの購入は不要です。

### 3. スマホで開く
- 表示されたアドレスをスマホで開いてログインし、「ホーム画面に追加」します
- 通知用に「ntfy」アプリを入れ、表示されたトピック名を登録します
- アプリの **「設定」→「接続テスト」** を押します（購入はしません）。×が出たら、その画面のスクショをClaudeに送ってください。投票サイトの画面に合わせて直します

更新するときは、同じ1行をもう一度貼り付けるだけです（設定はそのまま残ります）。

## 投票サイトの画面合わせについて

即PATとSPAT4の操作手順（`app/selectors/*.json`）は、**実際の画面ではまだ確かめていません**。
開発環境から投票サイトに接続できなかったため、ボタンの名前などが実際と違う可能性が高いです。
「接続テスト」ですべて○になるまでは、**練習モードかリハーサルモードで使ってください**。

払戻の確認はnetkeibaの結果ページで行います。読めないときは本番モードに限り投票サイトの照会画面で確認し、それでも分からなければ通知が来るので、アプリで結果を入力します。

## 注意

- 投票サイトには自動投票用の公式APIがないため、画面を自動で操作する方式です。**各サイトの利用規約に反する可能性があり、アカウントが停止されるリスクがあります。** ご自身の判断で使ってください
- netkeibaのページは1秒以上の間隔をあけて読み、同じページは一定時間キャッシュしています
- 投票サイトやnetkeibaの画面が変わると動かなくなることがあります。そのときは上の調整の手順で直してください
