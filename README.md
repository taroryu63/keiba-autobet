# 競馬自動投票

スマホから予想テキストを送ると、決めたルールで馬券にして、発走の数分前に自動で投票するアプリです。
中央（即PAT）と地方（SPAT4）に対応しています。

## 買い方のルール

**平日（複勝の転がし）**
- 予想の **◎だけ** を使います（★は無視）
- 500円で複勝◎を買い、的中したら払戻金を全額次のレースへ（100円未満の端数は残す）
- **4回連続で的中** したらその日は終了
- 外れたら500円から再挑戦。**資金3000円** を使い切ったら終了
- 前のレースの払戻が確定する前に次のレースの締切が来た場合、そのレースは見送ります

**土日祝**
- ◎と★があるレース：**単勝◎**（増額ルール）＋**ワイド◎-★** 各100円＋**複勝★** 各100円
- ★だけのレース：**複勝★** 各100円
- 単勝は100円から始め、外れるたびに100円ずつ増やします（100, 200, … 1000, 1100 …）。毎日100円から
- 投票の直前に単勝オッズを読み、**2.1倍以下なら単勝だけ見送ります**（ワイド・複勝は買う）
- **単勝が的中したら、その日の残りの予約はすべて取り消します**
- 前のレースの単勝が未確定のまま次の締切が来たら、「外れ」とみなして増額して買います（設定で「見送る」に変更可）
- 1日の **上限10000円** を超える買い目は「保留」にしてスマホに通知します。アプリで「上限を超えて買う」か「見送る」を選んでください。締切までに選ばなければ買いません

金額などの数字はすべてアプリの「設定」で変えられます。

## 予想の書き方

```
新潟
1R ★ 3.7.10
2R ◎ 4 ★ 5.7.9

東京
11R ◎ 2 ★ 3.6.9.12
11R 15:40 ◎ 2 ★ 3.6   ← 発走時刻は書いても書かなくてもよい
```

- 全角数字・全角スペース・「.」「・」「、」区切りでも読めます
- 発走時刻はnetkeibaのレース一覧から自動で取得し、取れなければ投票サイトの画面から読みます。それでも取れないときはスマホに通知が来るので、アプリで入力してください

## 仮想収支

「仮想収支」タブに日付と予想を貼ると、netkeibaからその日の結果（着順・最終オッズ・払戻）を取り込み、上のルール通りに賭けた場合の収支を計算します。

- 「発走5分前に投票、発走10分後に結果が分かる」として、本番と同じ順序で計算します（前のレースの結果待ちによる増額や見送りも再現します）
- 単勝2.1倍以下の判定は最終オッズで行います。本番は直前オッズなので、少しずれることがあります
- 上限を超えた日は「上限超え」と表示します（本番なら保留になるところ）

## 3つの投票モード

| モード | 動き |
|---|---|
| 練習 | 投票サイトに接続しません。結果はnetkeibaから取り込み、ルール通りに進みます（ペーパートレード） |
| リハーサル | 投票サイトにログインし、購入ボタンの直前まで入力して止めます。画面を撮影して残します |
| 本番 | 実際に購入します。サーバーの `.env` で `ALLOW_LIVE=1` にしたときだけ選べます |

**必ず「練習」→「リハーサル」→「本番」の順に進めてください。**

## 安全装置

- 購入前に、確認画面の合計金額がアプリの計算と一致するかを確認し、違えば購入しないで中止します
- 購入ボタンを押した後にエラーが起きた場合は自動でやり直さず、「要確認」としてスマホに通知します（二重購入を防ぐため）。購入履歴を見て、アプリで「買えていた／買えていなかった」を押してください
- 投票中にサーバーが再起動した場合も「要確認」にします
- 同じレースは二重に予約できません
- ログイン情報はサーバーの `.env` だけに置き、データベースや画面には出しません

## サーバーの準備

1. **日本国内のVPSを1台用意します**（さくらのVPS、ConoHa、AWS Lightsail東京など。月数百円〜。メモリ1GB以上）。投票サイトは海外からの接続を制限していることがあるので、日本のサーバーを使ってください
2. ドメイン（またはサブドメイン）をサーバーのIPに向けます（HTTPSに必要）
3. サーバーで次を実行します
   ```sh
   git clone <このリポジトリ> keiba && cd keiba
   cp .env.example .env
   nano .env          # パスワード・ドメイン・ログイン情報を入れる
   chmod 600 .env
   docker compose up -d --build
   ```
4. スマホで `https://<ドメイン>` を開いてログインし、「ホーム画面に追加」します
5. スマホに **ntfy** アプリを入れて、`.env` の `NTFY_URL` と同じトピックを購読します（投票した・失敗した・保留・結果などが届きます）

## 投票サイトの画面に合わせる（最初に必ず行う）

即PATとSPAT4の操作手順は `app/selectors/ipat.json`・`spat4.json` に書いてありますが、**実際の画面ではまだ確かめていません**。
開発環境から投票サイトに接続できなかったためで、ボタンの名前や入力欄の場所が実際の画面と違う可能性が高いです。最初に次の手順で合わせてください。

1. 調整ツールを実行します（**購入ボタンは絶対に押しません**）
   ```sh
   docker compose exec app python -m tools.calibrate ipat --venue 東京 --race 11 --horse 4
   docker compose exec app python -m tools.calibrate spat4 --venue 大井 --race 3 --horse 5
   ```
2. どの段階で止まったかが表示され、各段階の画面とHTMLが `data/shots/` に保存されます
3. `data/selectors/ipat.json`（初回に自動でコピーされる）の、止まった手順の `sel` を実際の画面に合わせて直します。止まった画面のスクリーンショットとHTMLを送ってもらえれば、こちらで直します
4. 最後まで通ったら、アプリをリハーサルモードにして実際のレースで試し、保存された画面で購入直前まで正しく入力できているかを確認します

払戻の確認はnetkeibaの結果ページを使います。netkeibaから読めないときは、本番モードに限り投票サイトの照会画面（`result` の手順）で確認します。どちらでも確認できなければ通知が来るので、アプリで結果を入力してください。

## 注意

- 投票サイトには自動投票用の公式APIがないため、画面を自動で操作する方式です。**各サイトの利用規約に反する可能性があり、アカウントが停止されるリスクがあります。** ご自身の判断で使ってください
- netkeibaのページは1秒以上の間隔をあけて読み、同じページは一定時間キャッシュしています
- 投票サイトやnetkeibaの画面が変わると動かなくなることがあります。そのときは上の調整の手順で直してください
